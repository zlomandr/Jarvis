# J.A.R.V.I.S. MK-VII

Голосовой ИИ-ассистент для Windows в стиле Железного Человека: HUD-нейромозг,
русский синтез речи с «шлемовым» ревербом, wake-word «Джарвис» и мгновенный
локальный перехват команд — без нейросети, пока она не нужна.

Брауз — локальный [OpenCode](https://opencode.ai) CLI и его модель
(в коде по умолчанию: `opencode/deepseek-v4.1-flash-free`, меняется одной
константой). Ничего не улетает в закрытые API — только то, что сам настроишь.

## Что умеет

- **Голос** — распознавание через Google Speech + авто-подбор живого микрофона;
  wake-word «джарвис / jarvis / жарвис / дарвис»
- **Голос-ответ** — edge-tts (русский мужской голос),DSP-обработка:
  металлическое эхо «изнутри шлема» + кэш ответов на диске
- **HUD** — интерактивная 3D-нейросеть на tkinter Canvas:
  клик — импульс, двойной — шторм, ПКМ — красный разряд, колесо — зум,
  перетаскивание — вращение
- **Мгновенные команды (мимо LLM)** — управление мышью, громкость, медиа,
  скриншот, таймер, заметки, долговременная память («запомни: ...»),
  погода (wttr.in), статус системы, диски, батарея, убийство процессов
- **Приложения и сайты** — карта доверенных приложений + поиск по
  ярлыкам Пуска; несуществующее приложение не запустится, запрос уйдёт в мозг
- **Зрение** — «что на экране» → снимок → модель описывает экран
- **Память** — `запомни: ключ — значение` пишется в `jarvis_memory.json`

## Установка

Windows 10/11, Python 3.10+ (проверено на 3.12), микрофон:

```bat
py -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python J.A.R.V.I.S.pyw
```

Опционально: положи рядом `jarvis.ico` — станет иконкой окна и панели задач.

Опционально: японский/другой акцент или другая модель — константа
`OPENCODE_MODEL` в начале файла и строка голоса `self.voice` в классе
`HybridVoiceEngine` (например `ru-RU-SvetlanaNeural`).

## Мозг (OpenCode)

1. Установи OpenCode Desktop (`https://opencode.ai`) и авторизуйся в нём —
   CLI появится в `%APPDATA%\ai.opencode.desktop\cli\<версия>\opencode-cli.exe`,
   скрипт находит его автоматически.
2. Выбери модель: `OPENCODE_MODEL = "opencode/<имя-модели>"`.
3. Сессия диалога непрерывна: ID пишется в `jarvis_v2_opencode_session.txt`,
   при устаревании создаётся новая автоматически.

## Автозагрузка

`Win+R` → `shell:startup` → положи туда ярлык на `J.A.R.V.I.S.pyw`
или добавь в реестр:

```bat
setx is not needed, run this once:
reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Run" ^
  /v Jarvis /d "\"C:\путь\к\pythonw.exe\" \"C:\Users\ТЫ\Desktop\Jarvis\J.A.R.V.I.S.pyw\"" /f
```

## Приватность

Все пользовательские данные (память, заметки, кэш голоса, последний скриншот)
лежат рядом со скриптом и **не должны попадать в публичные репозитории** —
в комплекте стоит `.gitignore`, который их отсекает.
